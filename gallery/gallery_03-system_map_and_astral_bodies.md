# Gallery — Phase 2: bodies (Worldsmith + EWoCS) and the system map (2026-09-14)
 
## Sources ingested
- **The WorldSmith 8.00** (Artifexian, spreadsheet): STAR, PLANETARY SYSTEM, PLANET, MOON and Calculations sheets ported formula-for-formula into `src/core/astro/worldsmith.ts`. Not ported (later, if wanted): GALAXY (stellar neighbourhood counts), APPARENT SIZE & BRIGHTNESS, TECTONICS, CLIMATE ZONES, POPULATION, CALENDAR.
- **OA EWoCS Prototype 0.9** (Orion's Arm classification): Mass, Composition, Aerosols, Terrestrial Types, Terrestrial Fluid Types, Misc Parameters → `src/core/astro/ewocs.ts` as tables + classifiers + shorthand builder. The "WIP Aerosol Revision" sheet was skipped (prototype).
## What was built
- **Body schema v2** in EWoCS order: orbit (sma AU/km, e, i, periapsis, map angle, Lagrange host/point, belt edges, rotation, tilt, locking, spin resonance) → star (mass, age, L/R overrides, colour) → mass & physical (M⊕, CMF, radius/density overrides, albedo, greenhouse, T override) → composition (gas fraction, volatiles, C/O, core, atmosphere class) → atmosphere (pressure, gas mix) → terrestrial type (surface type, fluid, liquid %, coverage/temperature-subtype overrides) → aerosols → misc (orbit, multi-world, rotation, life, history) → appearance (glyph motif, colour, rings).
- **Derived panel** on every body: spectral class, L/R/T, HZ, frost line, inner limit; period, periapsis/apoapsis, flux, Hill radius, moon zones, tidal-locking times and tides; density, radius, gravity, escape velocity, tropics/polar circles, horizon; equilibrium and surface temperature; mean molar mass, surface density, per-gas retention; EWoCS mass class, aerosol-band guess, temperature-subtype guess and the shorthand ("Vesperian Conlectic Tepidal TitanoCalidian Satellite"). Warnings for inner-limit, Roche/moon-zone, escaping gases, age > MS lifetime.
- **41 body presets** (stars M–B, brown/white dwarf, barycenter; Earth/Venus/Mars/Mercury-likes, ocean super-Earth, ammonia world, desert, snowball, lava, carbon, Chthonian; Jupiter/Saturn/Uranus/Neptune-likes, mini-Neptune, hot Jupiter; Luna/Europa/Ganymede/Titan/Io/Enceladus-likes; Pluto/Ceres; asteroids, comet, belts, orbital ring, Trojan). Each has a **low-fi glyph** (`glyph.ts`, 22 motifs: banded giants, cratered airless, cracked Europan, hazy Calidian, lava cracks, rings…) chosen automatically from the classification; a `portrait` asset overrides it — this is where the planetary map editor will plug in for inhabited worlds.
- **System map editor** (`layout.ts` + `SystemMap.tsx`): log/sqrt/linear/manual radius mapping; ellipses with the star at the focus; moon systems and orbital stations at a separate scale; L1–L5 (L3 when occupied) for every planet; belts as bands; heliocentric stations/cyclers on dashed orbits; annotations (rings, arcs, labels). Pan/zoom, click-to-inspect (full record editor in the side pane), drag-along-orbit (writes `map_angle_deg`), + Body / + Location quick-add, **Skeleton…** (Worldsmith classical system: star → HZ/frost/inner limit → Titius–Bode orbits → zone-appropriate presets → belts at the giants' resonances), **Export SVG** into `assets/`.
- **Schema versioning**: built-ins carry `version`; newer built-ins replace on-disk copies with a `.v<N>.json` backup; `"custom": true` opts out.
- **CSV**: `_exports/body.csv` now includes derived columns (`d_class`, `d_radius_km`, `d_period_d`, `d_surface_K`, …).
- **Demo vault** rebuilt from *Heliaris Solar System.png*: Mercury Space Gun, Aesculanus/Argentinus (Mercury L4/L5), Aglaea Ecliptic + transit-network ring, Phoebe Solar Research, Earth with Luna, orbital ring, Eos & Selene elevators, Hyperion/Theia (L4/L5), Mars with Port Kirin/Port Tarlessos skyhooks, Ares Depot, Nerio Castle (L5), Harmonia Ecliptic & Bellona Castle cyclers, Eros, Pallas/Styx fleetyards, Zeus, Antares, Asteria telescope, main belt, Jupiter + Galileans + Trojan/Greek camps, ringed Saturn + Titan/Rhea, Uranus, Neptune, outer belt.
## Verified
- 32 tests: Worldsmith functions reproduce the spreadsheet's Earth/Moon defaults to the digit (density 5.512, radius 0.99986, T 288 K, HZ 0.953–1.374, frost 4.85, inner limit 0.0073, Luna period 27.33 d / synodic 29.54 d, k₂ 0.048/0.821, locking 0.0122 / 1.01 / 4.78 Gyr, tides 1.00×); EWoCS shorthands match the Examples sheet (Earth, Jupiter, Titan, Pluto, Luna, Uranus); layout geometry (focus at star, L4 at +60°, moons inside moon scale); schema upgrade; glyph rendering; demo round trip.
- Headless Chromium: map renders, zoom, select, drag Mars along its orbit → angle saved and inspector follows; SVG export renders standalone.
## Known limits / next
- Gas-retention rule (exosphere = 1500 K × T/287) is pessimistic for cold worlds (flags Titan's N₂); it is the sheet's model — shown with a tooltip.
- Label collision on dense maps is not handled yet (leader lines / label offsets later).
- Binary systems: model as a `barycenter` body with the combined mass; stars orbit it. Circumbinary zones use the barycenter's overridden luminosity.
- Not yet: planetary (Mollweide/globe) editor that feeds body portraits; site maps; module/ship designer with constraint sets and silhouette sketcher (next); local web server + mobile layout.
